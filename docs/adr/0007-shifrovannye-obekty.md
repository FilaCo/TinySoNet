# ADR-0007: История — зашифрованные content-addressed объекты

Статус: принято, 2026-09-17

## Контекст

Нужны секретные чаты, в которых участвует не всё сообщество, при этом каждый член остаётся репликой.

## Решение

Единица хранения — зашифрованный объект с ID = hash. Реплики хранят и раздают объекты, не читая их. Формат — [design/02-objects.md](../design/02-objects.md).

## Последствия

- Доступ к истории = владение ключами.
- Флуд не отличить от секретного чата, квоты — только по соединению.
