# ADR-0003: Мультидевайс

Статус: принято, 2026-09-17

## Контекст

У человека есть телефон и десктоп.

## Решение

Пользователь ≠ устройство. У каждого устройства свой ключ, устройства пользователя связаны подписанными событиями привязки.

## Последствия

- Голос считается по пользователю (ADR-0005).
- Отвязка или потеря устройства требует ротации ключей.
