# ADR-0010: Все члены хранят все объекты

Статус: принято, 2026-09-17

## Контекст

NF1. Кроме того, если скачивается всё, по запросам не видно, в каких чатах участвует член (ADR-0009).

## Решение

Каждое устройство каждого члена хранит все объекты сообщества.

## Последствия

- Объём на телефонах ограничен, в MVP только текст.
- Дополняется слепыми ретрансляторами (ADR-0011).
