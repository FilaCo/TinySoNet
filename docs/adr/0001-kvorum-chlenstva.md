# ADR-0001: Изменение членства решает кворум

Статус: принято, 2026-09-17

## Контекст

Сервера нет, решать за сообщество некому. Один член не должен менять состав единолично.

## Решение

Добавление и удаление члена — предложение, которое принимается кворумом. Правила кворума — в [design/04-membership.md](../design/04-membership.md).

## Последствия

- Нужны детерминированные правила подсчёта при разрыве сети.
- Для добавления в MVP действует единогласие (ADR-0008).
