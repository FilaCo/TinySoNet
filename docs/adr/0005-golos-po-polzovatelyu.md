# ADR-0005: Единица голоса — пользователь

Статус: принято, 2026-09-17

## Контекст

С мультидевайсом (ADR-0003) голос по устройству даёт sybil: привязал ещё один телефон — получил ещё один голос.

## Решение

Один пользователь — один голос, с любого его устройства.
