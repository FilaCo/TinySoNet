# ADR-0005: Единица голоса — пользователь

Статус: принято, 2026-09-17

## Контекст

С мультидевайсом (ADR-0003) голос по устройству даёт sybil: привязал ещё один телефон — получил ещё один голос.

## Решение

Один пользователь — один голос, с любого его устройства.

## Последствия

- Конфликт голосов с разных устройств одного пользователя разрешён в [design/04-membership.md](../design/04-membership.md), M3: причинно поздний вытесняет ранний, конкурентные и различные считаются голосом «нет».
