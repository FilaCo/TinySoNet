# ADR-0008: Вступление: QR спонсора + единогласие

Статус: принято, 2026-09-17

## Контекст

Основной сценарий — личная встреча с участником.

## Решение

Кандидат сканирует одноразовый QR члена-спонсора → спонсор подтверждает кандидата (сверка отпечатков) → заявка уходит всем → нужно согласие всех, одно «нет» отклоняет. Заявка истекает по таймауту.

## Последствия

- Один член может блокировать любой приём (принято для MVP).
- Ослабление до кворума — после MVP.
