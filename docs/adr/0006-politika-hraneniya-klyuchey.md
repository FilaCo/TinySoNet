# ADR-0006: Исчезающие сообщения — возможны, но не в MVP

Статус: принято, 2026-09-17

## Контекст

История хранится шифротекстом (ADR-0007), поэтому её читаемость определяется ключами эпох.

## Решение

MVP хранит ключи эпох бессрочно. Архитектура обязана допускать удаление ключей по сроку.

## Последствия

- Открытый текст (кэши, индекс, превью) не хранится долговременно в обход ключей эпох.
- Forward secrecy обеспечивается политикой хранения ключей, а не протоколом.
