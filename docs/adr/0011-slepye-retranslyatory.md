# ADR-0011: Always-on слепые ретрансляторы

Статус: предложено, 2026-09-17

## Контекст

Телефоны большую часть времени офлайн; без always-on узла сообщения доходят, только когда два члена одновременно в сети.

## Решение

В сети есть **ретрансляторы**: always-on узлы без ключей сообщества (RPi, VPS, десктоп). Хранят объекты как есть и пересылают членам и другим ретрансляторам (mesh). Читать не могут. Не являются членами.

## Последствия

- Ретранслятор видит IP членов, объёмы и тайминги (A3 в модели угроз).
- Может удерживать объекты, но не может подменить (ID = hash).
- Открыто: кто добавляет ретранслятор, как члены у него аутентифицируются, срок хранения (backlog).
