# ADR-0004: События удалённого члена, конкурентные удалению, отвергаются

Статус: принято, 2026-09-17; момент удаления уточнён ADR-0013 (= коммит)

## Контекст

Удалённый член может сослаться на старых родителей в DAG и выдать новое событие за старое (backdating).

## Решение

Принимаются только события удалённого члена, причинно предшествующие событию удаления.

## Последствия

- Честные сообщения, отправленные при разрыве сети одновременно с удалением, теряются. Принято сознательно.
