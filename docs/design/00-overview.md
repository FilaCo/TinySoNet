# Обзор

P2P социальная сеть для маленьких закрытых сообществ (в духе RetroShare). Фокус: приватность, работа при блокировках, безопасность в границах сообщества.
Полигон для Cangjie Multiplatform: ядро `shared/` на Cangjie, приложения `iosApp/` и Android. Один разработчик.

## Требования

| ID | Требование |
|---|---|
| F1 | Пир создаёт сообщество |
| F2 | Пир предлагает добавить пользователя в сообщество |
| F3 | Пир предлагает удалить пользователя из сообщества |
| F4 | Пир начинает чат в сообществе |
| F5 | Пир пишет сообщение в чат |
| F6 | Пир создаёт секретный чат с частью членов |
| NF1 | Член хранит все объекты сообщества в зашифрованном виде; читает только свои чаты (ADR-0007, ADR-0010) |
| NF2 | Не-члены не читают и не изменяют данные сообщества — формализовано в [01-threat-model.md](01-threat-model.md) |

## Принципы

| Принцип | Суть |
|---|---|
| Идентичность = ключ | никнейм — метка; у каждого устройства свой ключ (ADR-0003); верификация через QR / safety numbers |
| Состояние = свёртка журнала | подписанные события образуют DAG; при любом порядке доставки пиры сходятся к одному состоянию |
| Членство — самое сложное | без глобального порядка нужны детерминированные правила для конкурентных изменений |
| Удаление = ротация ключей | старую историю у удалённого не отозвать |
| Доставка через ретрансляторы | телефоны офлайн, push требует сервера → слепые always-on ретрансляторы (ADR-0011) |
| Транспорт — абстракция | TCP/QUIC, ретрансляторы, Tor, обфускация, LAN/BLE/Wi-Fi Direct; bootstrap через инвайты, без публичного DHT |
| Своей криптографии нет | `stdx.crypto`, FFI к libsodium или готовой реализации MLS |
| Ядро sans-IO | IO, время и случайность внедряются → детерминированный симулятор сети и тесты |
| Headless/CLI-узел | macOS/Linux; два режима: ретранслятор (без ключей, ADR-0011) или always-on устройство члена (с ключами, ADR-0003); плюс отладка |

## Референсы

- MLS, RFC 9420 — Proposal/Commit.
- Weidner et al., «Key Agreement for Decentralized Secure Group Messaging» (DCGKA).
- Keyhive/Beehive (Ink & Switch), p2panda — децентрализованный контроль доступа.
- Matrix state resolution — конфликты состояния.
- Briar — транспорты при шатдауне; Berty (Wesh) — офлайн-first группы.
- Negentropy — синхронизация множеств.
